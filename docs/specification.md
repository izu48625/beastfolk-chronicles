# 獣界年代記｜プロジェクト概要（Phase 0 引継ぎ用）

**設計基準**: ユーザー提供『獣界年代記（仮称）｜BEASTFOLK CHRONICLES　複数AI共同開発用 総合仕様書 Ver.1.0【完全版】』（2026-10-16）。こちらは**短縮版の目次・要件整理**であり、完全版を置換しない。仕様の衝突時は完全版 → `docs/interfaces.md`（実装契約）の順でAI-0が解決する。

## コンセプト

- 古典国取りSLG風の簡素な2D地図（SVG）で、数十〜数百の獣人文明を観察する。
- 内政・外交・軍事・戦争・和平は国家AIが自動実行。プレイヤーは基本観察者、任意国家へ介入/委任切替。
- 1月=1ターン、世界暦0年開始。停止/1倍/5倍/20倍。自動歴史生成を主目的とし、全世界統一しても進行可能。
- 種族と国家は別: 1種族が複数国へ、1国家が複数種族を抱える。食性だけで能力を規定しない。
- 居住者個別AI化、3D、戦闘演出、常時外部LLM API、サーバー必須化は採用しない。

## MVP完成条件

- 1大陸50地域、初期10国家、獣人20タイプ、武将約100人。
- 獣人8能力（DOM/ECO/POW/DEF/MOB/REC/LOG/DIP）、個別生態と0〜5特性。
- 食糧・金・資材、出生・死亡・移住、農業/商業/兵站・収容力制限。
- 有効戦力の自動戦闘、隣接侵攻、攻城、外交、停戦、分裂/建国/滅亡。
- 武将の成長・死亡・後継者、構造化歴史年表（実イベント由来）。
- スマホ対応、IndexedDBセーブ+JSON入出力、同シード・同介入で完全再現。
- 500年×30シードの統合長期テスト。重大な参照・数値・無限ループエラー0。

## 技術・責任境界

- HTML5 / CSS / JS ES Modules / SVG / Node.jsでの純JSテスト。
- UI表示は状態の投影のみ。状態変更はAI-0のエンジンを経由。
- AI-1地図、AI-2生態経済、AI-3軍事外交国家AI、AI-4人物歴史、AI-5 UI、AI-6 QA、AI-0エンジン統括。
- 全AIは契約 `docs/interfaces.md`、個別責任 `docs/ai-tasks.md`、統合 `docs/integration.md` を参照。
