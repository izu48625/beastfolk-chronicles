# 武将システム実装記録（2026-10-16）

## 動作する機能
- 地域3枠：統治官・軍事官・参謀官。初期4地域＝12人。50地域に拡張後は150枠。
- 年1回の人材候補。国の民間種族人口構成に沿って候補種族を選出する。能力・年齢・忠誠は個別生成。
- AIの自動登用。空席を優先し、既存武将より役職適性が9点以上高い候補も優先して交代。元武将は予備役になる。
- 介入モードでの候補登用、既存武将の交代、予備役の地域配置、登用しない候補の自然失効。
- 年次加齢・死亡・君主後継・軍団長引継ぎ・史実に基づく年表。
- 滅亡国武将の捕虜・亡命・引退処理と捕虜登用API。ただし国取り・戦争の自動処理自体は未実装。
- 同シード再現性、旧v1セーブのv2への移行、同人物二重配置の禁止。
- iPhoneを想定した「人事・登用」タブ、地域の3武将、手動人事ON/OFF、候補と予備役一覧、「＋1年」ボタン。

## 仕様
- 世界暦1年1月（12か月経過後）を初回として、毎年年初に候補を生成。
- 手動操作は1命令の提出ごとに月が1か月進む。
- プレイヤーが人事を介入管理している国家では候補をAIが自動採用しない。
- 現段階はサンプル4地域・2国家・2種族のみ。人口と経済は固定で、武将と人事は変動。
- 捕虜獲得は軍事・滅亡処理が追加されて初めてゲーム中に発生する。架空の捕虜は作成しない。
- 新規外部API・課金なし。

## ファイル
- src/systems/officers.js：人物生成・役職・年次人事・滅亡国武将処理。
- src/core/engine.js, orders.js, validation.js, save.js：統合・検証・移行。
- src/ui/previewApp.js：ブラウザUI。
- tests/officer-system.test.mjs：シード再現、候補、交換、重複防止、セーブ旧版移行と捕虜登用。
