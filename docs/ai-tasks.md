# AI-1〜AI-6 共通担当依頼 / P0引き継ぎパケット

## 共通前提

- **基準**: ユーザー仕様書Ver.1.0（2026-10-16）＋ `docs/interfaces.md` v1。
- **作業開始前**: まず現HEAD/配布されたソースを確認。リポジトリ未作成なら作業成果をパッチ・ZIPで提出し、pushやPR済みと記載しない。
- **共通入力**: `WorldState v1`、`createRng`、`GameOrder`、`HistoryEvent`、関連モジュール。
- **禁止**: 担当範囲外ファイルへの無断上書き、外部LLMへの常時依存、サーバー・課金、`Math.random()`、シミュレーションのUI直接実行。
- **契約変更依頼先**: AI-0。メイン取り込み: AI-0のみ。

## AI-1 / 地図・世界生成（次フェーズP1）

**所有:** `assets/map/*`, `src/data/terrain.js`, `src/data/seedWorld.js`。

**入力**: 安定ID/領土/隣接/地形契約、シード+共有PRNG、国家・地域初期値の契約。**出力**: オリジナル架空大陸SVG（各 `<path data-province-id="province_XXX">`）、約50地域・10国の決定的初期データ、双方向neighbors、初期首都・地形/資材/食料潜在力。**公開関数候補**: `buildSeedWorld(seed, config, rng)`、`validateMapIds(svgIds, provinceIds)`（シグネチャ確定はAI-0）。**完了判定**: SVGと50個の地域IDが一対一、1つの大陸の連結グラフ、重複/欠損/非対称隣接0、各首都自領内、同じシードは同じ生成結果。**未担当**: 戦闘・国家AI・人口計算・UI操作。

## AI-2 / 種族・生態・経済・内政（P2、P1のデータ契約後）

**所有:** `src/data/species.js`, `src/data/traits.js`, `src/systems/ecology.js`, `economy.js`, `population.js`, `internalAffairs.js`。

**入力**: 解決後8能力、生態、`WorldState`、地域の地形/気候/資源、共通PRNG。**出力**: 初期20種のデータ、特性効果表、季節/収容力/食糧と資源の決定的計算、人口/徴兵負担/治安の計算、AI-3が呼ぶ内政命令の検証・適用関数。**公開関数候補**: `resolveSpeciesStats()`, `applyEconomy(world,context,rng)`, `applyPopulation(world,context,rng)`, `resolveInternalOrders(world,orders,context,rng)`。**完了判定**: 20種8能力0..100、不正数値なし、住民と軍人が二重計上されない、食糧不足でも即全滅しない、人口/資源の発散抑制、100年単体テストで範囲外0。**未担当**: 外交・軍事結果やシステム全体エンジン更新。

## AI-3 / 軍事・戦争・外交・国家AI（P3、P2の計算契約後）

**所有:** `src/systems/military.js`, `warfare.js`, `diplomacy.js`, `src/ai/nationAI.js`。

**入力**: 国家・地域・軍団・関係・種族能力・武将能力、共有PRNG、確定GameOrderとターン順。**出力**: `generateNationOrders(world,nationId,rng) -> GameOrder[]`、合法な隣接行軍/宣戦/交戦/占領/和平、停戦期間、要塞・地形・補給・偵察による数値戦闘、勝利/退却/損耗の構造化記録。**完了判定**: 10国放置で月次命令を発行、AIはworldを直接変更しない、兵員不足の徴兵/無宣戦攻撃を排除、所有権と駐留軍の状態不一致0、同シード再現、戦時の国境変更を確認。**未担当**: SVG描画、内政数式、武将生涯イベントのUI。

## AI-4 / 武将・君主・歴史（P4、P3の戦争イベント契約後）

**追加設計（P4の採用仕様案）**： [武将・人材循環システム v1.1](officer-system-v1.1.md) を必ず参照。各地域3枠、初期約150人、年次候補のAI登用／プレイヤー採否／既存武将との交代、滅亡国の敵将登用・亡命、予備役と世代交代を対象とする。現段階ではまだWorldState v1を変更せず、P4着手時にAI-0がschemaVersion、移行、命令と責任境界を確定する。


**所有:** `src/data/names.js`, `src/systems/officers.js`, `history.js`。

**入力**: 種族/国家、年齢・能力契約、戦争・外交・建国・技術の確定状態変更、共有PRNG。**出力**: 初期約100人の生成、経験成長・死亡・登用・後継者・指揮官解任、`HistoryEvent` の事実ベース生成・検索補助。**完了判定**: 死亡武将が君主/軍団長として残らない、生存国家の君主参照が常に有効、50〜100年で世代交代を観測、功績が実イベント由来、架空の偽実績なし。**未担当**: 国土SVG、UI、外交AIの意思決定。

## AI-5 / UI・Safari（P1に地図表示、P5に介入完成）

**所有:** `index.html`, `styles/*`, `src/ui/*`。`src/main.js` はAI-0専有、UI連携APIをAI-0に依頼。

**入力**: read-only WorldStateスナップショット、エンジン `advanceMonth` の戻り値、地域SVG、国力サマリー、HistoryEvent、プレイヤー命令API。**出力**: 縦画面の地図・国家・武将・種族・歴史タブ、再生 0/1/5/20倍、地図タップ/パン/ズーム、セーブUI、観察/介入モード切替。**完了判定**: iPhone Safari画面端がホームインジケータと干渉しない、連続タップ誤作動なし、地図色がゲーム状態に追従、500年進行を中断可能、UIからworldを直接書き換えない。**未担当**: 戦闘・人口・AIの判定式。

## AI-6 / QA・長期検証（P0から並行、P6本格）

**所有:** `tests/*`, `docs/qa-report.md`。本番モジュールは修正提案のみ。

**入力**: 仕様/契約、各担当の公開関数、シード、CIまたはNode.js。**出力**: 契約・再現性・セーブ継続・人口/軍/外交・500年×30シード・Safari試験レポート。**完了判定**: 不正参照・NaN・Infinite・クラッシュ0、非決定性の検出、指標（国家数、領土集中、建国/滅亡、人口/資源、戦争回数、速度、保存サイズ）をシード別に集計、異常の再現シードを提示。**未担当**: 実装修正の無断コミット。
